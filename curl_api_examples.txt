Schoolers API curl examples
===========================

Base URL:
  http://localhost:8000

The examples below use the gateway. Replace IDs with IDs returned by earlier
requests. Run the login command first and set ACCESS_TOKEN from its response.

HEALTH
------
curl http://localhost:8000/health | jq
curl http://localhost:8000/health/services | jq

AUTH
----
curl -X POST http://localhost:8000/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin1","password":"admin123"}' | jq

curl http://localhost:8000/api/v1/auth/me \
  -H "Authorization: Bearer $ACCESS_TOKEN" | jq

curl -X POST http://localhost:8000/api/v1/auth/refresh \
  -H 'Content-Type: application/json' \
  -d '{"refresh_token":"REPLACE_WITH_REFRESH_TOKEN"}' | jq

For protected requests:
  export ACCESS_TOKEN='REPLACE_WITH_ACCESS_TOKEN'
  export AUTH_HEADER="Authorization: Bearer $ACCESS_TOKEN"

SCHOOLS
-------
curl http://localhost:8000/api/v1/schools \
  -H "$AUTH_HEADER" | jq

curl -X POST http://localhost:8000/api/v1/schools \
  -H "$AUTH_HEADER" -H 'Content-Type: application/json' \
  -d '{"name":"Demo School","address":"1 Main Road","pincode":"560001","city":"Bengaluru","state":"Karnataka","country":"India","primary_contact":"9876543210","alternate_contact":"9876500000","primary_email":"admin@demo.school","alternate_email":"alternate@demo.school"}' | jq

curl http://localhost:8000/api/v1/schools/1 -H "$AUTH_HEADER" | jq
curl http://localhost:8000/api/v1/schools/1/stats -H "$AUTH_HEADER" | jq

curl -X PATCH http://localhost:8000/api/v1/schools/1 \
  -H "$AUTH_HEADER" -H 'Content-Type: application/json' \
  -d '{"name":"Demo School Updated","primary_contact":"9876543211"}' | jq

curl -X PATCH http://localhost:8000/api/v1/schools/1/features \
  -H "$AUTH_HEADER" -H 'Content-Type: application/json' \
  -d '{"route_enabled":true,"website_enabled":true,"library_enabled":false,"fees_enabled":true,"salary_enabled":false}' | jq

curl -X PATCH http://localhost:8000/api/v1/schools/1/status \
  -H "$AUTH_HEADER" -H 'Content-Type: application/json' \
  -d '{"status":"Active"}' | jq

curl -X DELETE http://localhost:8000/api/v1/schools/1 -H "$AUTH_HEADER" | jq
